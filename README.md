# Student Grade Management System

A simple Python application for managing student records, recording marks, calculating grades, and viewing academic performance.

## Features

- Register new students.
- View all registered students.
- Search for students by ID.
- Delete student records.
- Calculate individual grades automatically.
- Calculate the class average.
- Store student records in a JSON file.

## Technologies Used

- Python 3
- JSON

## How to Run

1. Make sure Python 3 is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
py main.py
```
